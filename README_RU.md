# Tower Defense Simulator Overlay
> [!IMPORTANT]
> Roblox TDS Strategy Overlay — это безопасный внешний оверлей, не внедряющийся в игру. Он **НЕ** внедряется в память `RobloxPlayerBeta.exe` и не изменяет файлы игры. Программа просто отображает прозрачное окно Windows поверх игры и использует встроенный инструмент распознавания текста (Windows OCR).

[Читать на русском языке](README_RU.md)

Ультралегкий **оверлей поверх всех окон (Always-On-Top)** для **Roblox Tower Defense Simulator**, написанный на C#, .NET 10, Dear ImGui (DirectX 11) и Native Windows OCR.

## Возможности
- **Поверх всех окон**: Прозрачно отображается над Roblox без влияния на производительность.
- **Windows 10/11 OCR**: Автоматически распознает номер волны с экрана и подсвечивает текущий шаг стратегии.
- **Скриншоты расстановки**: Просмотрщик карт расстановки с масштабированием и перетаскиванием (встроенный или в отдельном окне).
- **Карточка общей информации и снаряжения**: Держите главные заметки по стратегии перед глазами на протяжении всех волн.
- **Поддержка JSON и ZIP**: Экспорт и импорт стратегий вместе со всеми прикрепленными скриншотами в `.zip` архивах.
- **Локализация**: Полная поддержка русского и английского языков.

## Требования
- .NET 10

## Как скачать
1. Перейдите в раздел **Releases**.
2. Скачайте последний архив `TdsOverlayImGui.zip` или `TdsOverlayImgui.7z`.
3. *(Опционально)* Для наилучшего внешнего вида скачайте рекомендуемый шрифт из папки [`fonts/Roboto-Regular.ttf`](./fonts/Roboto-Regular.ttf): создайте папку `fonts` в директории с установленной программой и поместите файл `.ttf` внутрь.
4. Распакуйте архив и запустите приложение.

## Сборка из исходников
Требуется **.NET 10 SDK** (Windows 10/11).
```bash
dotnet publish -c Release -f net10.0-windows10.0.19041.0 -r win-x64 --self-contained true -p:PublishSingleFile=true
```
