# Tower Defense Simulator Strategy Overlay

> [!NOTE]
> Весь код проекта полностью написан с помощью **Google Gemini**.

> [!IMPORTANT]
> **Roblox TDS Strategy Overlay** — это полностью внешний, неинвазивный оверлей.  
> Программа НЕ внедряется в память процесса `RobloxPlayerBeta.exe`, не читает указатели игры, не модифицирует файлы и не триггерит античит Hyperion (Byfron). Оверлей рендерится как прозрачное окно Windows поверх клиента игры и считывает номер волны через нативный Windows OCR API.

[Read this document in English](README.md)

---

Ультралегкий, быстрый и отзывчивый **Always-On-Top оверлей** для **Roblox Tower Defense Simulator**, созданный на C#, .NET 10, Dear ImGui (DirectX 11) и системном Windows OCR. 

Помогает проходить сложные карты (Fallen, Hardcore, Special Events), автоматически отслеживая текущую волну, напоминая о способностях башен (Commander/DJ/Medic) и отображая пошаговые инструкции и карты расстановок для соло и мультиплеера.

## Возможности

- **Ультралегкий и портативный**: Один независимый исполняемый файл размером всего ~14 МБ, не требующий установки сторонних рантаймов.
- **Автораспознавание волн (Windows 10/11 OCR)**: Автоматически сканирует цифру волны на экране и подсвечивает нужный шаг стратегии без задержек и необходимости вручную кликать волны.
- **Поддержка мультиплеера (Trio / Quad / Duo)**: Удобное переключение между игроками (`Player 1`, `Player 2` и т.д.) с персональными шагами, колодами башен и картинками для каждого игрока.
- **Интерактивные чекбоксы задач**: Отмечайте выполненные действия прямо в оверлее кликом по галочке с сохранением прогресса между запусками.
- **Просмотрщик карт расстановки**: Отображение картинок внутри карточки шага или в отдельном независимом окне с зумом и перемещением.
- **Встроенный секундомер**: Замер общего времени матча, таймингов отдельных волн и фиксация кругов (Lap).
- **Звуковые оповещения способностей**: Таймеры и напоминания для прожима способностей Commander (Call to Arms), Medic, DJ и звуки смены волн.
- **Адаптивная прозрачность**: Автоматическое снижение непрозрачности окна до 20% при отведении курсора мыши в игру и плавный возврат при наведении (можно отключить в настройках).
- **Защита от захвата экрана**: Поддержка нативного `SetWindowDisplayAffinity` — оверлей невидим для OBS Studio, Discord Screen Share и других программ захвата.
- **Удобный импорт и экспорт**: Поддержка архивов `.zip`, прямого Drag & Drop файлов в окно программы и обмена стратегиями через буфер обмена.
- **Двуязычный интерфейс**: Мгновенное переключение между русским и английским языками прямо в настройках.

| Компонент | Требование |
| :--- | :--- |
| **Операционная система** | Windows 10 (версия 1809+) или Windows 11 (64-bit) *(необходимо для Windows Media OCR)* |

## Инструкция по использованию

### 1. Настройка и калибровка OCR
Для того чтобы оверлей автоматически переключал шаги при наступлении новой волны:
1. Откройте меню настроек в заголовке окна.
2. Включите опцию **«Звуковой сигнал <ocr> при смене волны»** и проверьте калибровку.
3. Нажмите кнопку **«Выбрать область экрана»**: на экране появится цветная рамка.
4. Переместите и растяните рамку вокруг счетчика волны в интерфейсе Roblox (например, `Wave 15/40` или просто `15`).
5. Закройте режим калибровки — оверлей начнет считывать номер волны автоматически.

### 2. Мультиплеерные стратегии и роли
- Если стратегия создана для нескольких человек, в карточке стратегии доступно переключение игроков (`Player 1`, `Player 2` и т.д.).
- При переключении игрока автоматически обновляются:
  - Рекомендуемый лоадаут (Loadout).
  - Карточка с общими инструкциями и назначенной ролью.
  - Пошаговые действия для каждой конкретной волны.
  - Персональные скриншоты расстановки для выбранной роли.

### 3. Просмотр карт расстановки (Placement Maps)
- В настройках можно выбрать режим: отображение картинки **внутри карточки шага** или **в отдельном независимом окне** (удобно для второго монитора).
- **Управление изображением**:
  - `Колесико мыши` — приблизить / отдалить изображение.
  - `Зажатие ЛКМ` — перемещение (панорамирование) по увеличенной карте.
  - `Клик СКМ (колесико)` — сброс зума и позиции к исходному размеру.

### 4. Интерактивные задачи (Чекбоксы)
- Пункты инструкции с синтаксисом `- [ ]` превращаются в интерактивные чекбоксы.
- Клик по чекбоксу помечает задачу выполненной (текст зачеркивается).
- Состояние сохраняется между перезапусками, а кнопка **«Сбросить галочки»** позволяет быстро очистить прогресс перед новой игрой.

### 5. Встроенный секундомер
- Расположен прямо под блоком выбора стратегии.
- Позволяет засекать общее время прохождения матча.
- Поддерживает старт, паузу, сброс и фиксацию кругов/сплитов (**Круг**), что удобно для сравнения таймингов волн.

### 6. Скрытие от стримов (OBS / Discord)
- В настройках активируйте опцию **«Скрыть оверлей от OBS и записи экрана»**.
- Оверлей останется видимым для вас на мониторе, но будет полностью скрыт в окне захвата игры, стримах Discord и записях через OBS Studio.

## Создание и обмен стратегиями

- **Встроенный редактор**: Создавайте собственные стратегии, настраивайте волны, шаги, колоды башен и добавляйте скриншоты расстановки из файлов или напрямую из буфера обмена.
- **Экспорт в ZIP**: Экспортирует стратегию в единый `.zip` архив, включающий `.json` разметку и все прикрепленные изображения.
- **Импорт / Drag & Drop**: Чтобы загрузить готовую стратегию, просто перетащите файл `.zip` или `.json` прямо в окно оверлея либо воспользуйтесь кнопкой **«Импортировать файл...»**.
- **Буфер обмена**: Стратегиями можно делиться и текстом через кнопки **«Экспорт в буфер обмена»** и **«Импорт из буфера обмена»**.
- Все данные сохраняются локально в папке с программой.

## Часто задаваемые вопросы (FAQ)

<details>
<summary><b>1. Безопасно ли использовать оверлей? Могут ли забанить?</b></summary>
Оверлей абсолютно безопасен. Он работает по тому же принципу, что и Discord Overlay, MSI Afterburner или Windows Game Bar: рендерит прозрачное окно через DirectX 11 поверх экрана и делает скриншот выделенной маленькой области для OCR. Никакого вмешательства в память игры, инъекций DLL и перехвата сетевых пакетов нет.
</details>

<details>
<summary><b>2. Оверлей пропадает при клике в Roblox / не отображается поверх игры</b></summary>
Убедитесь, что:
1. В настройках оверлея включена опция <b>«Поверх всех окон (поверх игры)»</b>.
2. Клиент Roblox запущен в оконном режиме или Borderless Windowed (если включен полноэкранный режим, нажмите <code>F11</code>).
</details>

<details>
<summary><b>3. OCR не видит номер волны или распознает его с ошибками</b></summary>
1. Проверьте калибровку: рамка OCR должна плотно охватывать цифры волны, не захватывая лишние иконки и полоски здоровья.
2. В настройках оверлея включите опцию <b>«Повышать контраст текста для OCR»</b>.
3. Проверьте масштаб дисплея в параметрах Windows (рекомендуется 100% или 125%).
</details>

<details>
<summary><b>4. Где хранятся мои настройки и стратегии?</b></summary>
Программа полностью портативна. Все файлы хранятся прямо в папке с оверлеем:
- <code>settings.json</code> — настройки приложения и координаты зоны OCR;
- <code>completed_tasks.json</code> — сохраненное состояние отмеченных чекбоксов;
- <code>strategies/</code> — файлы стратегий (.json);
- <code>images/</code> — прикрепленные изображения и скриншоты карт.
</details>

## Сборка из исходников

Если вы хотите собрать оверлей самостоятельно:

### Требования
- [.NET 10.0 SDK](https://dotnet.microsoft.com/)
- Операционная система Windows 10/11 x64

### Команды для сборки
```bash
# Клонирование репозитория
git clone https://github.com/icymarshm47/TdsOverlayImGui.git
cd TdsOverlayImGui

# Сборка оптимизированного одиночного исполняемого файла
dotnet publish -c Release -r win-x64 --self-contained -o ./publish
```
